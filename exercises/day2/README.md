# Day 2 Exercises

Work in `starter-scripts/` first, then compare with `solution-scripts/`.

These scripts are meant for a Unity LTS 2D project. They are not compiled by this repository's .NET CI.

## Exercise Order

1. Add health and death events.
2. Add player click damage.
3. Add weighted chest drops.
4. Add inventory UI text.
5. Add JSON save/load.

## Manual Validation

In Unity:

1. Create a 2D project.
2. Copy starter scripts into `Assets/Scripts`.
3. Create the objects described in `docs/day2-unity/07-mini-project.md`.
4. Fix compile errors and missing Inspector references.
5. Compare with `solution-scripts/`.
