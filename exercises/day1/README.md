# Day 1 Exercises

Work in `starter/` first. Compare with `solution/` after you have an implementation.

Recommended loop:

```bash
dotnet test src/IdleGame.Tests
dotnet run --project src/Day1.ConsolePlayground
```

If you want to turn the starter files into a real project, copy them into `src/IdleGame.Domain` one at a time and run the matching tests.

## Exercise Order

1. Inventory system
2. Weighted drop table
3. Offline reward calculation
4. Async fake API call
5. Event-driven health system

The tests in `src/IdleGame.Tests` are the executable specification.
